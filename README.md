# 🎙️ Nordhelm Voice Channel Generator Bot

Discord бот для автоматического создания временных приватных/динамических голосовых комнат («Создай свой канал / сцена-X») для сервера **Nordhelm RP**.

## 📌 Функционал
- 🔊 При входе пользователя в специальный канал-генератор (например, *«Зайди, чтобы создать»*) бот автоматически создает новый голосовой канал с именем `сцена-1`, `сцена-2` и т.д. в той же категории.
- 🔄 Автоматически находит первый наименьший свободный порядковый номер.
- 🔀 Автоматически мгновенно перемещает подключившегося пользователя в его новую созданную комнату.
- 🗑️ Автоматически удаляет созданную комнату, как только последний участник покидает её.

## 🛠️ Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/TATAP-345/nordhelm-voice-bot.git
   cd nordhelm-voice-bot
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения**:
   Переименуйте `.env.example` в `.env` и укажите данные вашего бота:
   ```env
   BOT_TOKEN=ваш_токен_бота
   CREATOR_CHANNEL_ID=1533052343665430590
   ```

4. **Запустите бота**:
   ```bash
   python main.py
   ```

## ⚙️ Права бота в Discord
Для работы механизма перемещения и создания голосовых каналов боту необходимы следующие права на сервере:
- `Manage Channels` (Управление каналами)
- `Move Members` (Перемещение участников)
- Интент **Voice States Intent** (`intents.voice_states = True`).
